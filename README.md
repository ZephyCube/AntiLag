# ZephyCubeLag v1.4.3

ZephyCube Lag Finder for Minecraft Bedrock Edition. Finds laggy chunks, caps mobs per chunk, clears mobs and items on low TPS, removes over-long redstone lines.

## Install

Download `ZephyCubeLag-v1.4.3.mcpack` from the Releases page and open it, or copy the `ZephyCubeLag` folder into your world's `behavior_packs` folder and add its `uuid` and `version` (from `manifest.json`) to the world's `world_behavior_packs.json`. Needs `@minecraft/server` 2.8.0.
